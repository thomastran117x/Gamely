# Support

Games is an early-stage project maintained without a guaranteed support response time.

## Setup and usage

Start with the [project README](README.md), then use the [backend](backend/README.md) or
[frontend](frontend/README.md) guide for component-specific work. Include the relevant operating
system, tool versions, command, and sanitized error output when requesting help.

## Bugs

Use the [bug report form](https://github.com/thomastran117/Games/issues/new?template=bug_report.yml)
after searching existing issues. Provide a minimal reproduction and remove credentials, tokens,
personal data, and unrelated logs.

## Feature requests

Use the
[feature request form](https://github.com/thomastran117/Games/issues/new?template=feature_request.yml)
to describe the user problem and desired outcome. A request is not a delivery commitment.

## Security and conduct

- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md), never through an issue.
- Report community-conduct concerns according to [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

For contribution and pull request questions, see [CONTRIBUTING.md](CONTRIBUTING.md).
